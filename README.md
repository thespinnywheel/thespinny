# SpinWheel — Multi-page website

A static, responsive wheel-spinner website with ready-made wheel templates.

## Included pages
- `index.html` — Home / Custom Wheel
- `templates.html` — all templates
- `yes-no-wheel.html`
- `random-name-picker.html`
- `giveaway-wheel.html`
- `food-wheel.html`
- `party-wheel.html`
- `classroom-wheel.html`
- `number-wheel.html`
- `decision-wheel.html`
- `movie-wheel.html`
- `about.html`, `privacy.html`, `terms.html`

## Features
- Working canvas-based spinner
- Edit/add/remove/shuffle choices
- Color themes
- Labels, confetti and sound toggles
- Adjustable spin duration
- Dark mode
- Responsive mobile layout
- Template buttons are real links and open working wheel pages
- No ad placeholders or fixed ad columns, so the layout does not overflow
- No backend required

## Hosting
Upload all files in this folder to any static host (Cloudflare Pages, Netlify, Vercel, GitHub Pages, cPanel, etc.).

Before launch, replace `YOURDOMAIN.in` in `sitemap.xml` and `robots.txt` with your real domain. Review and replace the legal placeholder text in `privacy.html` and `terms.html` for your actual business/site practices.
